# Web Dev Lab Assignment 3 - Dharika.dev Portfolio

A responsive multi-page portfolio website, upgraded from Lab 2 using modern CSS (Flexbox, Grid, animations, media queries).

## Pages
`assignment2.html` (portfolio landing) | `home.html` | `about.html` | `skills.html` | `projects.html` | `achievements.html` | `contact.html`

## Improvements Made
- **Hero:** colour-changing animated text ("a student developer.") and profile image on the right (floating animation)
- **Layout:** Flexbox for navbar, hero, about and footer; CSS Grid for cards (skills, projects, achievements)
- **Responsive:** on small screens the hero text sits above the image and grid items stack in one column
- **Design consistency:** shared `style.css`, CSS variables for the colour theme, equal spacing
- **Interactive:** hover and transition effects on buttons, links, cards and tags
- **Content:** more skills, extra project cards, new achievement

## How to View Responsive Behavior
1. Open `assignment2.html` in Chrome.
2. Press **F12**, then click the device toolbar icon (**Ctrl + Shift + M**).
3. Resize or choose Mobile / Tablet / Desktop presets.

## Breakpoints Tested
| Device | Width |
|---|---|
| Desktop | above 992px |
| Tablet | 768px - 992px |
